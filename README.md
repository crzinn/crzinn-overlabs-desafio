# Overlabs — API de filmes

API em Node.js, TypeScript e Fastify que consulta os filmes da Overlabs e retorna os dados transformados.

Versões utilizadas: Node.js **26.12.1**, npm **12.2.1** e TypeScript **5.9.3**.

## Instalar e iniciar

```sh
npm ci
npm start
```

Rota: **GET http://127.0.0.1:3000/filmes**

## Testes e tipos

```sh
npm test
npm run typecheck
```
